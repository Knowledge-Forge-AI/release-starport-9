# RS9 publisher instance review scaffold

This file is a review checklist only. It is not a GitHub Actions workflow,
publisher credential, destination proof, or publication authorization.

- Confirm the installed RS9 engine version and pinned template identity.
- Confirm the independently named publisher repository and branch.
- Confirm each registered consumer repository and selected Homebrew projection.
- Revalidate each consumer's existing `.rs9/` contract without modifying it.
- Record any remote GitHub observation separately; no observation means unknown.
- Keep configured, validated, qualified, and publication-enabled states distinct.
- Require separate authorization before repository creation, workflow dispatch,
  or any publication mutation.
