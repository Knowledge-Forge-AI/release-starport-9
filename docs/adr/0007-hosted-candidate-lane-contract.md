# ADR 0007: Hosted candidate lane and custody authority

Status: Proposed for source adoption; hosted qualification pending.

## Context

CONT1 is an accepted partial source checkpoint. The provider cannot supply real release capture or Docker/Nix/GPG qualification. Local prerequisites must not substitute for hosted behavior or prevent source review.

## Decision

A source lane contract drives matrices, expected receipts, gate requirements, artifact names and manager completeness checks. Hosted jobs freshly authenticate releases and compare a canonical projection that excludes transport timestamps and redirect URLs. Build and verification retain the same exact candidate bytes. Fixture signatures use isolated non-production authority.

Pages/Foundation jobs run after failed dependencies unless cancelled; observations run independently of package builds. Summary always runs and records missing inputs. A bounded attended adopt/collect operator owns the later manager action. No source-stage Git publication or production transport is used.

Native Linux wheels use honest candidate platform tags and remain non-promotable until policy is resolved. Run-resolved preparation pins permit real build evidence but block a reproducible qualification verdict.

## Consequences

Hosted execution health and generation qualification are separate. First-run evidence may be red and remains durable. Source tests prove fail-closed contracts without requiring live facilities. Production still needs reviewed pins, trust custody, project/environment setup, exact artifact promotion rules, post-sign RPM readback and independent production review.
