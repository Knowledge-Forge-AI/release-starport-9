# Fixed Theme Forge repository unsigned-input admission

Prepared source only. No policy adoption, original native qualification, consumer
adoption, signing, publication or deployment is established by this change.

`qualified_distribution_inputs()` remains the generic strict facade: every actual
promotion restriction refuses. The separate current-only
`qualified_theme_forge_packages_inputs()` has a literal target,
Knowledge-Forge-AI/theme-forge-packages, and returns unsigned inputs only. It is
not a caller-selected repository, a boolean waiver or an arbitrary token allowlist.
It invokes the same fresh collector/original-run/summary validators as the strict
entry and adds fixed-consumer and exact current policy/custody verification.

The original producer/summary token
`rpm-lint-policy-exceptions-not-raw-clean-not-fedora-qualified` remains unchanged.
The original global promotion-blocked field remains true when that token exists.
The scoped audit record preserves per-system/product raw status/counts/custody,
selected policy/evaluation identities and consumer source. It does not claim
raw-clean RPMs, official Fedora qualification, production signing or publication.
All authority/assembly flags remain false. Unknown, malformed, omitted-required,
misplaced or gratuitous restrictions refuse rather than being removed.

## Source and policy joins

The fixed consumer verifier requires a clean local P source tree, actual fixed-P
main/commit/tree API agreement, a complete non-truncated tracked-blob listing and
held physical bytes matching those blobs. The executing importer and mandatory
critical P inputs must also match the exact source-owned consumer hash bundle.
A caller's file inventory or copied public key is insufficient. An ignored or
untracked replacement for a mandatory path is refused even if its bytes match.
The verifier reuses existing read-only GitHub GET transport and adds no secret,
dependency, source-write or remote-write capability.

`tools/verification/current-rs9-inputs.json` is a fixed tracked descriptor. Its
closed schema and original-run/source coordinates must match the supplied typed
RS9 configuration, which the fresh facade independently recomputes against actual
original producer metadata and custody. A descriptor's “qualified” string is not
evidence of qualification. Caller JSON, target/waiver flags and saved inventories
cannot substitute for these joins. The actual prepared descriptor is explicitly
unadmitted with rs9=null; no qualified current original run exists for adoption.

Current preservation policy must already be complete, authorized, nonblocking and
selected from the authenticated RS9 source. Both RPM systems and all four exact
products are required. Retained full chunk evaluations, raw evidence, package
identities, source policy hashes, capture/closure/payload identities and all
original technical/native gates remain mandatory. The separate preservation
proposal is not adopted here; base current policy and loader remain unchanged.

The consumer body and fixed P metadata hashes are real prepared/source hashes.
The descriptor is separate, so it can later name a real adopted RS9 run without
embedding the consumer's own commit or creating a hash cycle. Any change to the
pinned consumer implementation/critical metadata requires a corresponding reviewed
source bundle update. No runtime manual waiver or extra attendance step is added.

Internal source/admission objects are process-local and invalidated on exit from
the fixed facade. JSON, copied dataclasses and released objects cannot be replayed
through lane selection. This is not protection against arbitrary interpreter
monkey-patching: actual authority is authenticated executing source, fixed target
and fresh recomputation. Returned audit JSON is never a signing capability.

## P integration and limits

The prepared P importer invokes this fixed facade, retains its existing source
readbacks and exact original-byte/architecture/origin/APT checks, and propagates
the limitation audit record into unsigned-routing.json. No signing, signed assembly,
real production-key client, Pages or full P native-three gate is implemented here.
The P9 source is probe-only; this importer/descriptor are not adopted there.
P's probe approval is separate from current RPM policy and production authority.

The maintained generator counterpart emits exactly the new importer and held
descriptor with a fresh projection binding. All existing P9 members, public key,
lock, recipes and workflows stay byte-identical. Canonical source remains untouched.

Pure tests exercise source/API/ZIP seams, actual shared collector/summary/raw/chunk/
role validators and the existing APT API. The sealed proposed policy loader is
used only in a disclosed controlled integration fixture. CLI evaluation fixtures
use its real pure evaluator; the GUI-positive consumer fixture simulates a native
producer statement and does not mint a live caller capability or prove native GUI
acceptance. All positive results are fixture-only/non-admitting; real current
inputs remain held. No test result authorizes policy adoption or publication.

## Paired proposal2 execution-source correction

The fixed entry checks the complete flat `src/rs9/*.py` source inventory against
the selected checkout. Loaded RS9 modules must originate from one package path,
with matching file/spec origins; imported RS9 helper functions must have source
filenames in that same inventory. Checks run before consumer/source admission,
on return or failure of fresh collection, after original-run validation, and
before the unsigned result returns. The existing source identity, builder digest,
clean Git tree and original API contracts authenticate the selected checkout.
This catches mixed installations; it is not hostile same-process Python confinement.
The executing package must reside in the exact physical selected `src/rs9`
checkout. Thus every `__file__`-rooted policy, catalog, caller contract and other
source-owned input belongs to the same adopted source; identical module copies
in a different source-data root are refused.
No policy, token, native gate, descriptor or production authority changes.
