2. **Nix Predicate and Short-Circuiting (`nix/nebular.nix`):**
   - `currentLinuxGraphics` evaluates:
     `stdenv.hostPlatform.isLinux && (product ? source_generation) && product.source_generation == currentCatalog.generation && currentAsset != null && product.version == (currentRow.version or null) && (product.commit or null) == (currentRow.commit or null) && (product.asset_sha256 or null) == currentAsset.sha256 && builtins.hashFile "sha256" (capture + "/payloads/${product.pname}/payload.tar.gz") == currentAsset.sha256`.

   - These Nix content checks supplement Python `ReleaseCapture` / `bind_catalog_product` authentication on an overridable `rs9-capture` flake input; they do not independently authenticate an overridable capture.
