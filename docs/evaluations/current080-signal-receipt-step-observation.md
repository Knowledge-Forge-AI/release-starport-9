# Nebular 0.8 signal scenario: closed step observations

This proposed diagnostic scope applies only after a failed original smoke
attempt for the authenticated Nebular 0.8.0 source on Linux x64, scenario
`C-signal`. The existing source readback verifies execution identity, package
version, the tools location and every pinned harness/support member. A generation
label or partial profile alone cannot enable the observation.

The projection consumes the already-read run record. It retains the existing ten
scenario step identifiers with only `pass`, `fail`, `unknown`, `missing` or
`duplicate`, plus bounded observed/unlisted/omitted counts. Unknown identifiers,
step details, errors, raw output, paths, PIDs and credentials are not retained.
The existing 64-entry scan bound and closed envelope validator remain in force.
These values are untrusted observations and confer no qualification authority.

The observation is independent of the historical cleanup observer. It does not
enable that observer, finalization fields, additional problem categories, raw
stderr, replay, commands or state. Passing outcomes, other source profiles,
other scenarios, ARM and Darwin keep their existing behavior. Optional source
readback or projection failure withholds metadata and preserves the failed gate.

Original campaign 42676173532 passed both full unit gates and all other executed
native lanes, but AMD64 APT failed a Nebular signal smoke run. The original
diagnostics do not establish the native cause. ARM was skipped because it depends
on the full native matrix; there is no original queued/null diagnostic evidence.
The separately approved conditional canonical-import correction remains held.

Owner adoption of this diagnostic-retention scope is required before a fresh
original campaign. All existing admission, timeout, dependency, cleanup, signing
and environment controls remain required. This adds no automatic retry or
production publication. Rollback removes the additional step projection without
deleting failed evidence or weakening any gate.
